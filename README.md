# 全球数字情报橘 · 博客

- 地址：https://rayli090602-source.github.io/
- 平台：GitHub Pages（Jekyll，$0，无广告，不用绑卡）
- 定位：不放视频，只放文字目录。每天一篇，一屏看完：日期 + 视频里那几条新闻，每条一句话概括 + 来源链接。
- 视频在 YouTube，博客链接放视频简介下面；博客每篇里也放回视频链接。

## 每天怎么发（和视频同步）

1. 视频最终确认、可以发布后，Muse 再发博客，不提前发。
2. 新建一个文件 `_posts/YYYY-MM-DD-今日全球信息差.md`，照着 2026-11-08 那篇抄格式：
   - 标题：`YYYY年M月D日 · 今日全球信息差`
   - categories: [日报]
   - video: YouTube 链接（发布后填，没有就留空）
   - 正文：按视频里的顺序编号，一、二、三……每条一句话 + 来源，查不到写“未查到”
   - 条数不固定，不一定 20 条，视频里有几条就写几条
3. 推到仓库后 GitHub Pages 自动上线，几分钟内能打开。
4. 复盘：每周 / 每月一篇，categories 改成 [复盘]，标题如《本周 5 件大事怎么连起来的》，会同时出现在首页和“复盘”页。

## 搜索

首页搜索框是自动的，搜标题和正文里的词，不用手动打标签、不用分类。分类只有两个：日报、复盘。

## 本地文件

本仓库就是全部源码：`_config.yml`、`index.html`、`archive.html`、`fupan.html`、`_layouts/`、`assets/`、`_posts/`。
